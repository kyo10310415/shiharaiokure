初期セットアップガイド

🚀 使い始めるための手順

  1. Google Cloud Console でサービスアカウントを作成
    Google Cloud Console にアクセスし、 新しいサービスアカウントを作成します。
    権限: 「編集者」または「Googleシート編集」を付与
  2. サービスアカウントのJSONキーをダウンロード
    サービスアカウント > キー > キーを追加 > JSON
    ダウンロードしたJSONファイルをBase64エンコードします：
    base64 -i service-account.json | tr -d '\n'
  3. Renderの環境変数に設定
    Render ダッシュボード > Environment から以下を設定：
    GOOGLE_SERVICE_ACCOUNT_JSON = (上記のBase64文字列) STUDENT_SPREADSHEET_ID = 1nwaXDkbkUX1FWlqGO4_Ph3_I9SkidXyx4KnviwlSeR8 PAYMENT_SPREADSHEET_ID = 1iqrAhNjW8jTvobkur5N_9r9uUWFHCKqrhxM72X5z-iM OUTPUT_SPREADSHEET_ID = (出力シート作成後に設定)
  4. サービスアカウントをスプレッドシートに共有
    各スプレッドシートを開き、右上の「共有」から
    サービスアカウントのメールアドレス（xxx@yyy.iam.gserviceaccount.com）を
    「編集者」として追加してください
  5. 出力スプレッドシートを新規作成
    認証設定が完了したら下記ボタンで出力用スプレッドシートを作成します
  6. 初回データ同期を実行
    「ダッシュボード」タブから「今すぐ同期する」を実行して
    初回データを取り込んでください
